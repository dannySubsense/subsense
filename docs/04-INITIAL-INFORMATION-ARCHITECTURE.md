# Initial Information Architecture

**Status:** provisional; no framework/component decision implied.

## Immediate release

```text
Index
├── Work
│   └── selected project records
├── Writing
│   └── approved project texts / notes
└── About / contact
```

The Index is an editorial entry point, not a marketing homepage. Work records should allow title/date/status where verified; orientation; selected media sequence; question/context; process/material/place; collaborators; and related writing. Sparse records must not show empty fields.

Writing is independent because the corpus includes substantive project text, especially `Temple For New Babylon/A Temple for New Babylon Final.pdf`, not just support copy. About/contact awaits approved current facts.

## Deferred seam

**Constellations** remains an architectural seam rather than a required route until an actual grouping has provenance, Danny’s interpretation, and a relationship claim. Raw archive browsing, rich media infrastructure, Recall/ICM/taste systems, and graph visualisation are later work.

## Reasoning

This structure honors the context packet’s Work/Writing/Constellations distinction while fitting the evidence: Sono-Textures is material/process rich; Sonic Salad is performance/site rich; Temple is writing rich. A small editorial surface is more truthful than simulating a mature cultural atlas from unreviewed source material.
